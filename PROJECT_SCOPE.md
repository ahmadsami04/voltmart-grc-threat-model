# VoltMart Electronics GRC Threat Model Project

## 1. Project Overview

VoltMart Electronics is a fictional mid-sized electronics retailer operating a web storefront, inventory management system, and point-of-sale (POS) terminals. This project develops a simulated governance, risk, and compliance (GRC) package to support preparation for an ISO/IEC 27001 audit.

## 2. Project Objectives

- Identify and document VoltMart's simulated IT assets and their owners.
- Create a data-flow diagram showing systems, network segments, and information exchanges.
- Perform STRIDE threat modelling and risk ranking.
- Map relevant ISO/IEC 27001:2022 Annex A controls to identified risks.
- Prepare evidence collection materials and mitigation recommendations.
- Publish a documentation website and final handover package.

## 3. Scope

The simulated environment includes an e-commerce storefront, application and database servers, payment gateway integration, POS systems, inventory systems, employee and administrator workstations, identity management, networking, backups, and centralized logging.

## 5. Assumptions and Limitations

- VoltMart's architecture and asset details are fictional assumptions created for this educational exercise.
- No real customer, payment-card, or employee information will be used.
- No production infrastructure will be accessed or tested.
- Asset relationships and data flows will be documented consistently across the inventory, diagrams, and subsequent risk assessments.
- The project demonstrates audit preparation but does not constitute an actual ISO 27001 certification audit.
